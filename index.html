A 3D Virtual Dressing Room is an AI-powered fashion visualization project that allows users to virtually preview clothing on a digital representation of themselves. The system combines computer vision, image processing, 3D visualization, and AI-based techniques to create an interactive virtual try-on experience. The project focuses on helping users visualize different outfits, colors, and clothing styles before making a selection, creating a more personalized and engaging digital shopping experience.

SNS Analytics Dashboard

SNS Dashboard is an AI/ML-powered financial news analytics platform designed to analyze stock-market-related news and identify its sentiment. The system uses Natural Language Processing, text preprocessing, feature extraction, and machine learning techniques to classify financial news into positive, neutral, and negative sentiment categories. The project transforms unstructured financial news into meaningful visual insights through an interactive dashboard, helping users understand sentiment patterns, analyze news trends, and explore market-related information in a more structured and accessible way.
